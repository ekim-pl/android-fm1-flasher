# Screenshot gallery

FM-1 Flasher **0.10.0 / 31**, captured on Android 16 at 1080 × 2400. These are actual screens of the Google Play test variant using a test Firebase project. Devices and Tasks show the disconnected state; no hardware update is simulated. Firmware descriptions remain in their authors’ languages. Select an image to open the original PNG.
