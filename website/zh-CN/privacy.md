# 隐私政策 — FM-1 Flasher

## 发布者与联系方式

ekim.pl@gmail.com。生效日期：2026 年 11 月 15 日。本文说明 FM-1 Flasher 如何处理数据。

## 本地信息

本应用无需账户，不含广告、分析或追踪 SDK。收藏、浏览偏好、主题与语言选择、缓存目录、预览图片、固件包和下载元数据保存在应用的私有存储中。操作日志（最多 256 KiB）保存在应用私有存储中，重启后仍保留。日志包含时间、操作、USB/MIDI 端口事件、传输阶段和错误信息，不记录原始 MIDI 流量或固件内容。日志中的 URL 查询参数和片段会被移除。可在实验功能设置中导出 JSON Lines 文件或清除日志。不会自动上传日志。导出的文件保留在您选择的位置，可能包含设备名称、USB 路径和技术错误信息，请在分享前检查。乐器名称、已读取的 USB 序列号、指定的存储芯片类型、最近的固件标识和任务历史（目标、固件包哈希、阶段和结果）保存在本地。普通连接日志不包含序列号。在应用会话保持打开时，可以恢复最近删除的有效固件包。这些数据不会上传给应用发布者。

## 网络连接

联网时，应用检查已启用的目录来源，并可获取其允许的预览图片。Firmware Hub 默认启用；raw.githubusercontent.com 上的 awesome-fm1 和自定义来源需用户启用。已关闭的来源不会自动发起请求；立即检查是用户明确发起的一次请求，也适用于已关闭的来源。用户发起固件包下载后，应用访问 GitHub 发布服务或批准的作者网址。每个目录每 24 小时最多请求一次，包括失败的尝试。可选的后台目录检查使用 WorkManager，默认关闭；离线模式会暂停此任务。所有请求均使用 HTTPS。应用不会自动安装固件。

## 外部服务可见的信息

服务器运营方会收到请求的网址、连接的 IP 地址及标准 HTTPS 连接元数据。应用发送通用的技术性 User-Agent 标头，不用于识别个人或设备。请求不会附带收藏、设置、设备内存内容、MIDI 标识或账户标识。各服务器运营方依据自己的隐私政策处理技术日志，应用发布者不控制其保留或处理方式。

## USB MIDI

应用读取用户明确选择的 FM-1 的标识，并在用户确认更新后通过 USB MIDI 传输所选固件包。USB 设备信息和 MIDI 响应用于管理本地会话，不会发送到网络服务或应用发布者。

## 存储、删除与离线使用

本地数据保留在设备上，直到用户在应用中删除、通过 Android 设置清除应用数据或卸载应用。删除固件包会保留收藏。目录、来源规则和本地固件包元数据存储在 SQLite 中。删除订阅会保留来源记录、已知撤回状态、固件包和收藏；清除应用数据或卸载会删除固件库和偏好设置。Android 应用数据备份已禁用。应用没有服务器账户，也没有由发布者保存的用户档案需要删除。离线模式下，应用不刷新目录，也不下载固件包或预览图片，先前保存的内容仍可使用。

## 政策变更与问题

相关应用更新及项目代码仓库将发布更新后的政策。如有隐私问题，请联系 ekim.pl@gmail.com。
