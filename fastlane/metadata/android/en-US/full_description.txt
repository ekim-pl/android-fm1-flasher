Manage M-VAVE FM-1 firmware with Devices, Library and Tasks on Android 14+.

Devices
Read each USB MIDI instrument, give it a name and assign a downloaded compatible package. An OTG hub can connect several instruments. The app writes one instrument at a time.

Library
Search Firmware Hub and optional Awesome FM-1/custom catalogs, filter by source/category, keep favorites and use saved packages offline. Check package integrity and compatibility before writing. A queued/running task pins its package against deletion or replacement. Ordinary valid package removal has Undo during the current app session.

Tasks
Review one plan with device names, versions and hashes. Approve it once to start sequential jobs. Stop after the current instrument without interrupting its write. Keep individual results and bounded stage history. An interrupted job is unconfirmed and never automatically resumes a partial transfer.

Reconnection
Multiple instruments require inline pairing of the unique returning unit with uninterrupted neighbors. A lost neighbor, hub reset or ambiguous ports blocks further writes. USB addresses are not physical socket numbers; serials are not validated cross-mode hardware identities. Conservative automatic reconnect is limited to a single eligible USB/MIDI device. Android may request USB permission again after re-enumeration.

Settings and experimental tools
English, Polish and Simplified Chinese; light, dark and system themes; About/privacy available offline. Optional background checks refresh catalog information; some sources fetch firmware bytes to identify packages, but offline-library downloads and installations remain explicit. Experimental tools include MIDI logging, diagnostics, flash maps, backup import, m-bootloader installation, stock boot restoration, ROM firmware installation and same-device backup restoration. Writes require a reviewed plan, exported backup and confirmation; factory data stay protected.

Requirements and status
Android 14+, USB Host/OTG and MIDI, FM-1 instruments, data cables and stable power. A powered hub is recommended; the app cannot measure its power quality. Firmware descriptions remain in their authors’ language. Physical FM-1/hub acceptance for this release is pending. Use firmware-specific backup tools where available; OTA does not automatically back up data. The Android fleet queue is not ported to the unverified iOS host.
