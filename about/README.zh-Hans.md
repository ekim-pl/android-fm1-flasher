# FM‑1 Flasher

启用 **设置 → 实验性功能** 后，将显示 MIDI 日志、闪存检测和恢复。此设置默认关闭并会保存。关闭后会停止日志并清除恢复计划；操作期间无法更改。恢复功能仍需实体硬件验证。

独立的实验性应用，用于浏览固件并通过 USB MIDI 更新 **M‑VAVE FM‑1**。

## 功能

- 浏览多个目录中的固件、搜索和收藏，离线使用已下载的固件包。
- 管理目录来源，并按来源筛选固件库。
- 在目录或刷写页面选择已下载的固件。
- 安装前验证固件包的完整性与兼容性。
- 计划内重启后，仅有一台 USB 设备和一个符合条件的 MIDI 端口时自动重新连接。
- 可选的实验性功能包含只接收数据的 MIDI 记录器、闪存芯片检测和范围严格受限的 ROM 恢复；ROM 恢复尚未在实体设备上验证。
- 支持浅色、深色和系统主题，以及简体中文、英语和波兰语界面。

## 管理固件来源

打开 **设置 → 固件来源**，选择应用使用的目录。**The Firmware Hub 默认启用**，**Awesome FM-1 默认关闭**。

- 启用或关闭来源，查看其状态、上次成功检查的时间及下次允许检查的时间。
- 选择 **添加目录来源**，输入与 Firmware Hub 使用相同 JSON 格式的 HTTPS 目录地址。填写名称、设置检查间隔，并配置允许的固件包及图片网址。**保存并检查** 可在启用新目录前查看其内容。
- 打开 **详情与配置**，编辑自定义来源或选择 **立即检查**。检查遵守各来源的间隔，两次尝试至少相隔 24 小时，失败也计入限制。一个来源失败不会阻止其他来源更新。
- 使用 **按来源筛选** 浏览某个目录，包括该来源的收藏及已下载固件包。移除自定义订阅后，已下载文件、收藏及已知撤回记录仍会保留。
- **恢复默认来源设置** 会启用 Firmware Hub 并关闭 Awesome FM-1，同时保留自定义订阅和已下载固件包。

已关闭的来源不会自动请求任何数据，包括图片。你仍可主动选择 **立即检查**，单次检查已关闭的来源，而不启用它。**在后台检查目录** 默认关闭；启用后，会在联网时按各来源的间隔检查已启用的目录，不会下载或安装固件。离线模式会暂停这些检查。

本地固件库保存已下载固件包、收藏、当前选择和每个固件包的来源。刷写只使用已保存的文件，不访问网络。离线模式无法发现上次成功检查目录后发布的撤回。

## Awesome FM-1

[Awesome FM-1](https://github.com/ekim-pl/awesome-fm1) 是本应用的配套社区项目，收录 **M-VAVE FM-1** 固件项目。它通过额外目录补充 Firmware Hub，提供开发者网站、固件包直接下载地址和 GitHub 项目发布链接。仓库保存描述、版本信息及下载链接；固件文件仍由各自发布者托管。

应用已预先配置此来源。要使用它，请关闭离线模式，打开 **设置 → 固件来源** 并启用 **Awesome FM-1**。遵守来源的刷新间隔并成功检查后，目录条目即可显示，无需手动输入目录地址。

欢迎帮助完善目录：通过 issue 报告过期条目，或提交 pull request，提供固件项目或固件包地址及简短说明。协作指南见 [Awesome FM-1 仓库](https://github.com/ekim-pl/awesome-fm1#contributing)。

收录于目录并不代表已确认硬件兼容性。目前 SHRUB 条目的闪存芯片兼容性未知，因此仍禁止刷写。这些目录没有经过验证的发布者签名；固件包完整性检查和兼容性限制仍然有效。

Android 设备须支持 USB Host/OTG 和 MIDI。请备份设备数据，确保 USB 供电稳定，并确认目标设备和固件包。
