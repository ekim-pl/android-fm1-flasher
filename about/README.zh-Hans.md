# FM-1 Flasher

面向 **M-VAVE FM-1** 的独立固件管理器。Android 通过**设备 · 固件库 · 任务**组织 OTG 集线器上的多台乐器，一次仅写入一台。

## 您的乐器

在**设备**逐台读取乐器，在**详情**命名，根据已知硬件指定芯片类型并选择已下载固件包。**添加到计划**把设备与固件绑定。名称和颜色用于整理视图，不证明物理设备身份。

## 一个安装计划

在**任务**检查设备名称、版本和固件哈希，然后选择**在 N 台乐器上安装**。这会批准计划，不再显示普通的第二次确认窗口。每个任务传输前再次检查。**处理完此乐器后停止**会完成当前操作，保留其余任务。

历史保存各任务的结果和阶段。进程中断后，活跃任务变为未确认，写入不会从已保存百分比自动恢复。在验证完成前保持 USB 和电源连接。固件可能改变设置；OTA 不会自动备份数据。

## 通过集线器重新连接

多设备情况下，在计划内重启后，使用**任务卡片中的配对操作**确认返回的乐器。其他连接必须始终连续，只能有一个候选设备。集线器重置、邻居断开、序列号冲突或 MIDI 端口不明确会阻止后续写入。

USB 地址不是物理集线器端口号，型号/版本不是唯一设备标识。USB 序列号跨模式的唯一性尚未实机验证。多设备自动配对保持关闭。保守自动路径仅适用于没有 MIDI 邻居、Android 只看到一个合格 MIDI 端点和一个 USB 设备的情况。重启后可能再次需要系统 USB 授权。

失去连接或进程重启后，保存的名称需明确重新配对。读取并实际辨认乐器，移除相关待处理任务，关联保存的名称，再指定芯片类型。成功表示已验证返回的固件身份，而非完整闪存回读。仍需真实 FM-1/集线器验收。

## 共享固件库

**固件库**集中提供搜索、收藏和下载。**筛选与排序**展开类别、排序和来源。已保存固件可离线使用。任务会固定其固件包，阻止删除或替换。普通有效包删除可在当前应用会话内撤销。

在**设置 → 固件目录来源**，Hub 默认开启，Awesome FM-1 默认关闭。自定义 HTTPS 目录使用支持的 JSON、批准的固件包/图片 URL 范围和 1–168 小时检查间隔。先保存配置，**立即检查**是独立操作。失败后仍遵守间隔并保留此前缓存。可以明确检查关闭的来源，但不会对它自动请求。

后台目录检查可选且默认关闭，不会下载或安装固件。离线模式停止网络获取和后台检查，但不能发现本地目录尚未得知的撤回信息。目录中的哈希本身不能认证发布者。

## Awesome FM-1

[Awesome FM-1](https://github.com/ekim-pl/awesome-fm1) 是 FM-1 固件项目、说明及发布者链接的社区目录。固件文件保留在作者处。在设置启用预配置来源，无需手动输入 URL。可以在仓库报告过期条目或贡献项目。

## 工具与平台

设置提供英语、波兰语、简体中文，浅色/深色/系统主题、离线、关于和隐私。实验功能默认关闭，启用后显示 MIDI 日志及恢复工具。只接收的日志在连接/写入期间停止。

芯片检测针对独立 ROM/download 模式设备，不会自动关联 MIDI 乐器。ROM 恢复需要单独批准的备份/写入计划，仅限已识别的原厂 V15 应用区域；不写引导加载器，也不会在 OTA 失败后自动执行。实机恢复未经验证。

Android 需要 **14+**、USB Host/OTG、MIDI、数据线和稳定供电，建议使用独立供电的集线器。 未来计划推出 iOS 移植版。目前没有 iOS 版本，也未公布发布日期。

## 诊断与存储清理

应用始终在本地保存操作日志（按日保存，默认保留七天；每天最多 256 KiB，总计最多 10 MiB），重启后保留。日志包括时间、操作、USB/MIDI 端口变化、安装阶段和捕获的错误，不记录原始 MIDI 流量或固件字节。在**设置 → 实验功能**中使用**导出操作日志**（JSON Lines，`.jsonl`）或**清除操作日志**。导出打开系统文件选择器，不会自动上传。清除需一次确认，不会删除已导出的文件，后续事件仍会继续记录。独立的 MIDI 日志工具用于实时原始 MIDI 诊断。

**设置 → 清除已下载固件**在一次确认后删除全部下载包与元数据，包括损坏及孤立文件，并清除当前选择和单包撤销记录。收藏、目录来源、乐器名称、任务历史和恢复备份保留。请先删除排队任务；操作进行中或存在排队/运行任务时禁止清理。离线安装前必须重新下载固件。

**设备 → 模式与闪存芯片**提供分开的 MIDI 读取、下载模式和芯片检测卡片。检测成功会弹窗显示结果，之后关闭并重新开启乐器以返回 MIDI 模式。默认离线条目是临时的，自定义名称和排队目标会保留。来自同次更新旧端口的延迟 USB 断开事件不会中止下一阶段；其他乐器或集线器断开仍会阻止写入。

## 全屏设置

**设置**使用完整页面，并分为界面、固件库、实验功能和应用卡片。语言与主题直接通过单选项选择。来源列表、来源编辑、各固件包兼容性和隐私政策均使用完整页面。顶部返回和系统返回逐级导航；原先的固件库/设备/任务页及非敏感表单草稿在活动重建后保留。密码和令牌输入不会保存到活动状态。仅删除确认和芯片检测结果仍使用弹窗。


Android 目录来源支持 thefirmwarehub、awesome-fm1、GitHub 发布及附件（repo-url）和直接 FWSC 文件（pkg-url）。来源设置支持 Basic、Bearer、自定义 API 密钥请求头以及 OAuth 2.0（浏览器 PKCE 和 Client Credentials）。凭据在本地加密；手动兼容性声明仅适用于对应的 SHA-256。新的网络及认证适配器仅在 Android 实现；Apple 后端保留原有 Hub 流程。


已完成任务的历史默认保留 30 天，可在设置中更改保留期限或清除已完成的历史。排队和运行中的任务、备份及未确认会话记录不会被清除。诊断日志可保留 7、14 或 30 天。写入或读取日志时删除过期文件；应用未使用时，将在下次活动时清理。手动清除会删除保留的每日日志，不会删除已导出的副本。
