Android 14+ acceptance checklist

Baseline: minSdk 34, compileSdk/targetSdk 36, version 0.6.0-experimental (8).

Automated:
  ANDROID_HOME=/path/to/sdk ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:bundleRelease
  ANDROID_HOME=/path/to/sdk ./gradlew :app:connectedDebugAndroidTest
The instrumentation test verifies that immutable PendingIntent callbacks arrive
without fill-in extras. Actual USB authorization is queried from UsbManager.

Pending manual acceptance on API 34, 35 and 36:
- Install and upgrade; preserve downloads, favorites, language and theme.
- Browse, download, restart offline and validate a saved package.
- Check keyboard, display cutout, system bars, back gesture, rotation and tablets.
- Deny notification permission on API 33+; flash initiation must remain usable.
- Grant/deny USB permission; unplug during permission dialog; retry connection.
- Rotate while permission dialog is open; retry safely, never start an unintended flash.
- Start flashing, background the activity, turn the screen off, return via notification.
- Test process termination: never automatically resume a partial firmware write.

Physical FM-1 required:
- Verify both planned restarts and USB permission after each re-enumeration.
- Verify single-device reconnect and explicit selection with multiple devices on a hub.
- Confirm neighboring instruments remain untouched.
- Verify JEDEC detection in download mode.

Remaining implementation review:
- Activity recreation currently discards pending USB callbacks; verify the retry flow.
- Audit library-task/service lifecycle separately from the foreground flash lifecycle.
- Process death does not persist an interrupted-flash marker; assess and implement
  an explicit unconfirmed-result message before claiming full lifecycle coverage.
