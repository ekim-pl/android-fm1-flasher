# Firmware developer integration — release proposal

This proposal adds a translated developer guide and source-integration issue template to the existing Pages deployment. It documents the existing Android source providers, private GitHub releases and publisher-operated licensing; it does not introduce a licensing backend or DRM.

Before release: build and check Pages; verify the catalog example against the Android parser; exercise a private GitHub release with valid, expired and revoked credentials, including asset redirects and offline behavior; review translations and install a real package on supported hardware. Access to a private test repository and hardware are required for the latter checks. Do not promise validated private-source support before this acceptance work is complete.

The release version and publication date are intentionally unassigned; select them when the acceptance checks are complete.
