GitHub Actions — 0.10.0

TWO DISTRIBUTION BUILD WORKFLOWS
Both run only on workflow_dispatch. The Android application ID is
pl.ekim.fm1_flasher. Tags alone do not start a build or publish a release.

F-DROID (.github/workflows/fdroid.yml)
Always passes -Pfm1Analytics=false. Runs shared/Android tests and release lint,
then assembles an unsigned release APK. Rejects Firebase and Google Play services
in the resolved release runtime dependencies. Artifact: fdroid-no-firebase-apk-<run>.
No Firebase configuration, signing key or store credentials are used.
This prepares the SDK-free distribution; it does not submit to F-Droid or establish
repository acceptance. The old publication/fdroid recipe is historical and is not
used by this workflow. F-Droid repository signing/build integration is separate.

GOOGLE PLAY (.github/workflows/google-play.yml)
Always passes -Pfm1Analytics=true -Pfm1AnalyticsEnvironment=production for release
lint and bundle assembly, and checks that Firebase Analytics is resolved.
There is no analytics toggle. Builds a signed AAB in the google-play environment.
Artifact: google-play-firebase-bundle-<run>. The publish input defaults false;
explicitly selecting it uploads to the internal testing track. No production
publication occurs in this workflow.
Required secrets: FIREBASE_PRODUCTION_ANDROID_JSON, ANDROID_KEYSTORE_BASE64,
ANDROID_KEYSTORE_PASSWORD, ANDROID_KEY_ALIAS, ANDROID_KEY_PASSWORD.
GOOGLE_PLAY_SERVICE_ACCOUNT_JSON is needed only for upload.

RELEASE FIXTURES (BOTH BUILD WORKFLOWS)
Configure FM1_FIXTURE_ARCHIVE_URL and FM1_FIXTURE_ARCHIVE_SHA256 as repository
variables. The pinned archive supplies v15.fwsc, v16.fwsc and catalog.json.
Missing fixtures or skipped release tests fail the workflow; they are not bypassed.
Current local tests may skip these external fixtures and are not release approval.

LOCAL TEST BUILDS
F-Droid equivalent:
  ./gradlew -Pfm1Analytics=false :app:assembleDebug
Google Play equivalent, using a TEST project (never production in debug):
  ./gradlew -Pfm1Analytics=true -Pfm1AnalyticsEnvironment=test :app:assembleDebug
Place test configuration in app/firebase/test/google-services.json (ignored by Git).
Both debug APKs use the same app ID and debug certificate; install one at a time.
Store certificates can differ; moving between stores requires compatible signing.

OTHER WORKFLOWS
android-ci.yml: unit tests, SDK-free and Firebase compile/lint checks, APK artifacts
and Android API 34/36 instrumentation. This is CI, not distribution publication.
pages.yml: site validation on branches/PRs; deployment from the default branch.
promote-production.yml: separate manual promotion of an already-tested internal
versionCode to production; no build. Uses google-play-production and a service account.

Build workflows do not establish Play account access, F-Droid acceptance, signing
continuity or physical FM-1/hub safety. Complete those checks before publication.
