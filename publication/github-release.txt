Experimental Android test release with USB download-mode flash chip detection.

## Changes
- Added Detect chip (download mode) to the Flasher screen.
- Uses the m-flasher RAM loader and ONLINE_DEVICE command (0xFC0A) to read JEDEC ID.
- Recognizes older FM-1 flash (0x856014) and newer flash (0xB36014); other IDs remain unknown.
- Detection does not erase or program flash. Loader sources and MIT attribution are included.
- Added detection instructions and English, Polish and Simplified Chinese UI strings.

## Usage
Connect exactly one instrument in JieLi USB download mode (4C4A:8057), open Flasher and choose Detect chip. After reading the ID, power cycle into MIDI mode, connect and select the reported chip type. Results are not transferred automatically to a new USB connection.

## Validation
- Debug APK and release AAB builds passed.
- Debug and release lint passed.
- JVM tests: 61 passed, 2 optional fixture tests skipped, no failures.
- Emulator: Flasher button and no-device instructions checked.
- APK signature matches the previous 0.5.1 test release.

The new detection path has not been validated on a physical FM-1. This is a debug-signed test APK for Android 8.0+ with USB Host/OTG, not a Google Play release. Back up instrument data before firmware updates.
