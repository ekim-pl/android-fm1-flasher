FM-1 Flasher 0.6.0 — Android 14+

## Changes
- Requires Android 14 (API 34) or newer; target and compile SDK remain API 36. Android 8–13 are no longer supported.
- Simplifies MIDI device discovery and callbacks, per-app language settings and permission handling.
- Checks the actual USB permission grant instead of relying on immutable PendingIntent result extras.
- Validates the selected USB device before starting the foreground flash service and handles startup failures.
- Updates system bar, display cutout and keyboard insets; fixes a cold-start crash.
- Adds device tests for cold launch and immutable permission callbacks.

## Validation
- JVM tests: 61 passed, 2 optional external-fixture tests skipped.
- Debug/release lint, debug APK and release AAB builds passed.
- Android 16 emulator: both instrumentation tests passed (cold launch and immutable USB callback); app launch and catalog loading checked.
- Documentation build and all 44 generated HTML pages passed link validation.
- Android 14/15 and physical FM-1 USB flashing still require validation; see the attached acceptance checklist.

## Installation
The APK is signed with the same debug key as the previous test release. It is a test build, not a Google Play production artifact. Back up instrument data before firmware updates. Automatic reconnection and download-mode chip detection still require physical hardware testing.
