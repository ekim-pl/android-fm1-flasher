FM-1 Flasher 0.6.4 experimental — restored app identity

## Changes
- Restores the original FM-1 Flasher name and package ID `pl.ekim.fm1_flasher`.
- Keeps the MIDI logger, chip detection and ROM recovery features.
- Updates installation descriptions in English, Polish and Simplified Chinese.
- Version code: 12. Requires Android 14+.

## Installation
This debug-signed prerelease updates the original FM-1 Flasher app when signed with the same certificate. It does not update or migrate data from the separate `pl.ekim.fm1_flasher.experimental` app. Export any recovery backups from that app before uninstalling it.

Physical USB recovery remains unverified on hardware.
