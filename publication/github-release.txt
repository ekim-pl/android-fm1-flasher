# Multiplatform FM-1 Flasher 0.9.2 — prerelease draft, build 23

Prepared test build; this file does not publish a release.

Pełnoekranowe ustawienia, edycja źródeł i zgodności paczek oraz polityka prywatności dostępna z ustawień. Hierarchiczny powrót i zachowanie niesekretnych pól po odtworzeniu Activity.

Warstwa CatalogProvider: thefirmwarehub, awesome-fm1, repo-url (wydania GitHub i paczki FWSC), pkg-url (bezpośredni plik). Zachowano zgodność z wcześniejszymi katalogami JSON. Ręczna zgodność jest przypisana do SHA-256, a nie nazwy pliku.

Uwierzytelnianie źródeł: Basic, Bearer, klucz API w nagłówku i OAuth 2.0 — PKCE oraz Client Credentials. Szyfrowane poświadczenia, odświeżanie tokenów, kontrola stanu callbacku i izolacja nagłówków między originami. Nowe adaptery są implementacją Androida.

Weryfikacja: 191 testów jednostkowych zaliczonych, 4 pominięte z powodu zewnętrznych fixture’ów; 44 testy instrumentacyjne. Debug APK/test APK, lint, zasoby, witryna i metadane Kotlin/iOS. Szczegóły oraz SHA-256 w qa/0.9.2-test23.txt.

Debug APK jest przeznaczony do testów na Androidzie 14+. Brak nowej weryfikacji fizycznego FM-1/huba, natywnej aplikacji iOS/Xcode i logowania u produkcyjnego dostawcy OAuth; OAuth sprawdzono na kontrolowanych odpowiedziach testowych. Nie jest to pakiet sklepu Play.
