First public GitHub test release of the experimental Android firmware browser
and USB MIDI updater for M-VAVE FM-1.

Requires Android 8.0+, USB Host/OTG, Android MIDI and stable instrument power.
Download FM1-Flasher-0.5.1-debug.apk from Assets and install it on your phone.
The APK uses the same debug signing key as the previously shared test build.

Features:
- Firmware catalog, favorites, verified downloads and an offline library.
- Downloaded-firmware picker in Flasher; catalog selection sets the same package.
- Automatic reconnection after planned restarts when exactly one USB device
  and one eligible MIDI endpoint are present. Android USB permission is required.
- English, Polish and Simplified Chinese; light, dark and system themes.
- Portrait and landscape layouts.
- Short, dedicated offline About documents, license and privacy policy.

Verification: clean-clone debug build, release/debug lint and JVM tests passed
(58 passed, 2 optional external-fixture tests skipped). Documentation links were
checked. An earlier build successfully flashed a physical FM-1 according to a
user report; this build and automatic USB reconnection still need hardware tests.

This is a debug-signed test APK, not a store release. With multiple devices,
confirm the new port manually after restarts. An interrupted update, wrong
package or wrong instrument selection can require hardware recovery. The app
does not provide backups or recovery; back up your instrument first.

Assets:
- FM1-Flasher-0.5.1-debug.apk — Android test build.
- FM1-Flasher-0.5.1-debug.apk.sha256 — SHA-256 checksum of that APK.
- FM1-Flasher-0.5.1-test-checklist.txt — manual test checklist (Polish).
