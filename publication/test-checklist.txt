FM-1 Flasher — prepared-build test checklist

Installation
- Install the supplied APK as an update to the existing app.
- Check that downloaded packages, favorites and the last firmware selection remain saved.

About
- Open About. It should contain a short description of features, requirements
  and privacy, without build instructions or the project's release history.
- The installed package version is read by the app and shown only in the About
  header; it is not hard-coded into README files.
- Switch between Polish, English and Simplified Chinese. The short description
  should follow the interface language.
- Check light, dark and system themes and portrait/landscape rotation.
- Open the license and privacy policy from About, then close each document.
- Enable offline mode and open About and the documents again.

Privacy policy
- Open it from Settings as well. It should not reference specific app releases,
  regardless of language.

Checks completed before handing over the APK
- JVM tests and lint, plus APK and AAB builds.
- Bundled documents match their source files.
- All three short descriptions are present and the technical project README
  is absent from the APK.
- Files referenced by local document links are available.

Scope: About content, documents and packaging. Physical FM-1 flashing was not
repeated when preparing this build.
