Play Console foreground service declaration — proposed text

Permission/type: FOREGROUND_SERVICE_CONNECTED_DEVICE / connectedDevice

User-visible task:
The user explicitly selects a USB MIDI FM-1 instrument, downloads and selects a
compatible firmware package, and confirms installation. During this update the
app uses USB MIDI SysEx to exchange requests and transfer firmware to that one
instrument. It does not automatically select another connected instrument.

Why a foreground service is needed:
The session must continue when the user switches to another app or turns off
the screen. Stopping the data transfer during a firmware write can leave the
instrument requiring hardware recovery. An ongoing notification displays the
current stage/progress and opens the app. The service uses a time-limited wake
lock and ends its foreground operation on completion or failure. It is not used
for scheduled catalog refreshes or advertising. After a planned restart, the app automatically picks a new eligible MIDI port
only when Android reports exactly one USB device and one MIDI endpoint. USB
permission and FM-1 identity checks still apply. Multiple devices or ports
require explicit selection.

Reviewer access notes:
Catalog, language/theme settings, favorites and downloads work without login.
Firmware transfer requires a physical M-VAVE FM-1 and a phone with USB Host/OTG
and MIDI support, plus a data cable and stable hub power. An emulator cannot
demonstrate a real instrument update. Bluetooth updating is not supported.

Recording script for a physical-device review demonstration:
1. Show the app version and select the target FM-1 USB port.
2. Show device identity and a previously downloaded compatible package.
3. Confirm the target and start the update.
4. Switch apps and show the ongoing progress notification while transfer runs.
5. With one USB device, show automatic port reconnection after each restart and
   approve Android USB permission if requested. With multiple USB devices, show
   explicit port selection. Show final identity confirmation and notification removal.

Do not claim this recording exists: no physical FM-1 was available in this task.
