发布者与联系方式 ekim.pl@gmail.com。生效日期：2026 年 11 月 15 日。本文说明 FM-1 Flasher 如何处理数据。

本地信息 应用无需账户且无广告。标准构建不包含分析 SDK。可选统计构建包含 Google Analytics for Firebase，在明确同意前保持关闭。可选私有来源可能需要自己的凭据或 OAuth 账户。收藏、浏览偏好、主题与语言选择、缓存目录、预览图片、固件包和下载元数据保存在应用的私有存储中。操作日志（最多 256 KiB）保存在应用私有存储中，重启后仍保留。日志包含时间、操作、USB/MIDI 端口事件、传输阶段和错误信息，不记录原始 MIDI 流量或固件内容。日志中的 URL 查询参数和片段会被移除。可在实验功能设置中导出 JSON Lines 文件或清除日志。不会自动上传日志。导出的文件保留在您选择的位置，可能包含设备名称、USB 路径和技术错误信息，请在分享前检查。乐器名称、已读取的 USB 序列号、指定的存储芯片类型、最近的固件标识和任务历史（目标、固件包哈希、阶段和结果）保存在本地。普通连接日志不包含序列号。在应用会话保持打开时，可以恢复最近删除的有效固件包。这些数据不会上传给应用发布者。 来源提供程序选择、公开认证配置、Basic 用户名、OAuth 客户端 ID/范围和固件包兼容性声明保存在本地。密码、API 密钥、OAuth 访问/刷新令牌、客户端密钥和待处理的 PKCE 验证器使用 Android Keystore 密钥加密，存于独立于目录元数据的私有存储。秘密输入字段不写入操作日志或活动保存状态。认证请求头仅发送给配置的资源原点，跨原点跳转时移除；令牌 POST 跳转被拒绝。可选 OAuth 登录会打开浏览器并联系配置的授权/令牌服务器，运营方依据自己的政策处理认证。这些请求不携带乐器标识或设置。删除来源或恢复其内置默认配置会删除对应凭据；卸载或清除应用数据会移除应用保存的凭据。删除订阅后，非敏感来源历史和出处可保留。

网络连接 联网时，应用检查已启用的目录来源，并可获取其允许的预览图片。Firmware Hub 默认启用；raw.githubusercontent.com 上的 awesome-fm1 和自定义来源需用户启用。已关闭的来源不会自动发起请求；立即检查是用户明确发起的一次请求，也适用于已关闭的来源。已启用来源的检查会联系 GitHub 或批准的发布者。仓库或直接固件包检查可能获取固件头部或完整 FWSC 文件以识别并计算哈希，启用后台检查后也适用。用户选择下载后才保存经过验证的离线固件库副本。常规检查按来源设置的 24–168 小时间隔进行，失败尝试也计入。明确替换凭据或完成 OAuth 授权后可重新检查。可选的后台目录检查使用 WorkManager，默认关闭；离线模式会暂停此任务。所有请求均使用 HTTPS。应用不会自动安装固件。

外部服务可见的信息 服务器运营方会收到请求的网址、连接的 IP 地址及标准 HTTPS 连接元数据。应用发送通用的技术性 User-Agent 标头，不用于识别个人或设备。除用户明确为来源配置的认证外，请求不会附带收藏、设置、设备内存内容、MIDI 标识或账户标识。各服务器运营方依据自己的隐私政策处理技术日志，应用发布者不控制其保留或处理方式。

USB MIDI 应用读取用户明确选择的 FM-1 的标识，并在用户确认更新后通过 USB MIDI 传输所选固件包。USB 设备信息和 MIDI 响应用于管理本地会话，不会发送到网络服务或应用发布者。

存储、删除与离线使用 本地数据保留在设备上，直到用户在应用中删除、通过 Android 设置清除应用数据或卸载应用。删除固件包会保留收藏。目录、来源规则和本地固件包元数据存储在 SQLite 中。删除订阅会保留来源记录、已知撤回状态、固件包和收藏；清除应用数据或卸载会删除固件库和偏好设置。Android 应用数据备份已禁用。应用没有服务器账户，也没有由发布者保存的用户档案需要删除。离线模式下，应用不刷新目录，也不下载固件包或预览图片，先前保存的内容仍可使用。

政策变更与问题 相关应用更新及项目代码仓库将发布更新后的政策。如有隐私问题，请联系 ekim.pl@gmail.com。

可选使用统计：应用询问一次，之后可在设置中更改。启用后 Google 处理页面名称、操作结果和类别、耗时、应用实例标识符、应用/系统/设备信息及网络元数据。这些数据是化名数据，并非匿名数据。不会附加乐器身份、序列号、名称、私人来源网址、凭据、固件内容或日志。广告存储、广告标识符及广告个性化均关闭。同意前的事件被丢弃。离线模式暂停收集并请求重置本地 SDK 数据；已经开始的上传可能完成。撤回同意停止收集并重置本地分析数据，但不会删除已发送给 Google 的数据。生产配置计划将用户和事件数据保留两个月，汇总报告可能保留更久。Google 按其隐私政策处理数据（https://policies.google.com/privacy）。隐私请求请联系发布者。
