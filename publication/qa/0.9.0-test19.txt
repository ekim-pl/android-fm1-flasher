IMPLEMENTATION
- Android Devices / Library / Tasks navigation; compact collapsible library filters.
- Per-instrument names, colors, observed identity/serial, attachment generations,
  memory selection and package selection. Saved identities never automatically
  bind to a new connection; explicit pairing resets memory-type evidence.
- Persistent immutable jobs pin device, attachment, package key and SHA-256.
  A single plan approval starts sequential work. The complete plan is validated
  before the first write; each device/package is checked again before its job.
- Pinned packages cannot be replaced or deleted. Valid ordinary package removal
  has Undo for the current app session, with no confirmation modal.
- Atomic per-job outcomes and bounded stage history. Process interruption marks
  active jobs unconfirmed; no automatic transfer resumption or automatic recovery.
- Stop-after-current finishes current write/verification and retains remaining jobs.
- USB/MIDI callbacks and polling preserve lost-sibling evidence. Hub detach,
  lost/replaced sibling, ambiguous return or conflicting serial stops the plan.
  Port-pair ambiguity and multiple MIDI endpoints on one USB device block writes.
- Permission requests are serialized, use unique immutable callback nonces and
  attachment epochs. Reconnect approval also retains the full MIDI generation.
- Logger pauses without an extra question; recovery remains a separate opt-in flow.
- English, Polish and Simplified Chinese UI, About and privacy descriptions updated.
  Observed serials and task history stay in private storage, not network requests.

HARDWARE GATE / KNOWN LIMITS
No physical FM-1 or OTG hub is attached to this environment. Emulator and deterministic
transport tests do not prove descriptor timing, power stability, cross-mode serial
uniqueness or real flash success. Multi-device automatic pairing remains disabled.
A single candidate with uninterrupted siblings is paired inline by the owner.
There is no reliable physical hub-socket map in the used Android API. Firmware
model/version is not a physical UID. The original conservative automatic reconnect
for a single USB device remains available. Return verification checks model/version,
not a complete flash-memory readback. Do not swap indistinguishable instruments in
the middle of a transition. A false continuity alarm stops the job conservatively.

iOS retains the previous single-instrument controller. The Android fleet store and
queue adapter are not ported to Core MIDI. No Mac/Xcode or physical iOS validation,
IPA, iOS parity claim, or GitHub publication is included in this test build.

BEFORE PUBLISHING
Test with at least two real FM-1 units and the intended OTG hub: individual identity
reads; distinct package assignments; normal -> OTA -> final return; one inline pairing
per unverified return; stop-after-current; permission denial; process interruption;
unexpected sibling/hub disconnect in a controlled non-writing phase. Record null or
duplicate serials and mode changes. Do not deliberately unplug a live flash write.
Use this test APK for owner verification before approving a 0.9.0 GitHub Release.
