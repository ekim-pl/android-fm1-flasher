BEHAVIOR
Firebase-enabled builds collect from the first online launch after settings load.
Settings → Usage statistics → Share usage statistics is on by default and can be disabled.
SDK-free builds still contain no Firebase SDK and expose no analytics switch.
The default is a preference, not a stored record of explicit user consent.
An explicit opt-out survives restart, updates, and privacy-notice version changes.
Legacy analytics-consent.json DENIED migrates as disabled; new choices are stored in
analytics-preference.json. Damaged/unreadable preferences fail closed.
Offline and disabled events are discarded, never replayed on re-enable.
