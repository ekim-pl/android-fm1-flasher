Per-source firmware colors — local development verification
Base: bda15d9 (0.9.5-experimental.29). This feature is not published to GitHub Releases.

Settings → Firmware sources → Source color offers 8 named colors plus Automatic.
The source name and colored marker appear on firmware cards (including downloaded
packages) and in package details. Choice is local, stored in source-colors.json.
Built-in sources have distinct defaults; other source IDs have stable automatic colors.
Source removal retains existing color choices for local provenance. Restoring built-in
source defaults restores their automatic colors. Color changes do not reconfigure
providers, credentials, catalog freshness or package compatibility.
